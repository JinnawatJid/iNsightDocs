## 2.7.X JSON Web Token (JWT)

**JSON Web Token (JWT)** เป็นมาตรฐานอุตสาหกรรม (RFC 7519) ที่ใช้สำหรับสร้างและส่งผ่านข้อมูลแบบเข้ารหัสในรูปแบบ JSON โดยมีจุดประสงค์หลักเพื่อใช้ในการยืนยันตัวตน (Authentication) และการส่งข้อมูลที่ปลอดภัยระหว่างสองฝ่าย

**จุดเด่นที่สำคัญ:**
*   **ไร้สถานะ (Stateless):** เซิร์ฟเวอร์ไม่จำเป็นต้องเก็บสถานะเซสชัน (Session) ของผู้ใช้ไว้ในหน่วยความจำ เพราะข้อมูลทั้งหมด เช่น รหัสผู้ใช้หรือสิทธิ์ จะถูกรวมไว้ในตัว Token เอง ทำให้รองรับผู้ใช้จำนวนมากได้ง่าย
*   **ความปลอดภัยทางดิจิทัล:** JWT จะถูกเซ็นกำกับ (Signature) ด้วยรหัสลับ (Secret Key) หรือคีย์สาธารณะ/ส่วนตัว ทำให้มั่นใจได้ว่าข้อมูลภายใน Token ไม่ถูกปลอมแปลงระหว่างการส่ง
*   **ความกะทัดรัด (Compact):** สามารถส่งผ่าน URL, POST parameter, หรือ HTTP Header ได้อย่างสะดวกรวดเร็ว

**การประยุกต์ใช้ในระบบ:**
ระบบ CreditInsight ไม่ได้ทำหน้าที่เป็นผู้สร้างหรือออก (Generate) JWT ด้วยตนเอง แต่ระบบถูกออกแบบให้ทำงานร่วมกับระบบยืนยันตัวตนส่วนกลางขององค์กร (เช่น Single Sign-On) เมื่อผู้ใช้งานเข้าสู่ระบบผ่านระบบส่วนกลางสำเร็จ จะได้รับ JWT Token กลับมาเก็บไว้ที่ฝั่ง Frontend (เช่น ใน Cookie หรือ Header) จากนั้นในทุกๆ การร้องขอข้อมูล (API Request) ระบบจะนำ JWT นี้ส่งมาให้ Backend เพื่อทำการ**ถอดรหัส (Decode)** ซึ่งจะช่วยให้ระบบสามารถดึงข้อมูลรหัสพนักงาน (Username), บทบาท (Roles), และรหัสสาขา (Branch Code) ออกมาเพื่อใช้ตรวจสอบสิทธิ์ในการเข้าถึงฟังก์ชันต่างๆ ตามระดับสิทธิ์ (Role-Based Access Control) ต่อไป
