## 2.7.X Express.js

**Express.js** เป็นเว็บเฟรมเวิร์ก (Web Framework) สำหรับ Node.js ที่ได้รับความนิยมสูงสุด ถูกออกแบบมาให้มีความมินิมอล (Minimal) ยืดหยุ่น และไม่บังคับโครงสร้าง (Unopinionated) ทำให้เป็นเครื่องมือที่มีประสิทธิภาพในการสร้างเว็บแอปพลิเคชันและ API

**จุดเด่นที่สำคัญ:**
*   **ระบบ Middleware:** เป็นกลไกหลักที่ช่วยให้สามารถแทรกโค้ดเข้าไปในระหว่างกระบวนการรับ Request และส่ง Response ได้ง่าย เช่น การตรวจสอบสิทธิ์การเข้าใช้งาน, การแปลงรูปแบบข้อมูล เป็นต้น
*   **การจัดการ Routing:** มีระบบจัดการเส้นทาง URL (Routing) ที่แข็งแกร่ง ช่วยให้นักพัฒนาแยกแยะจุดให้บริการ (Endpoints) ได้อย่างเป็นระเบียบตามรูปแบบ RESTful API
*   **ประสิทธิภาพสูง:** เนื่องจากเป็นเฟรมเวิร์กขนาดเล็กที่ไม่ได้แนบเครื่องมือที่ไม่จำเป็นมาด้วย ทำให้ตัวระบบทำงานได้รวดเร็ว

**การประยุกต์ใช้ในระบบ:**
Express.js ถูกใช้เป็นโครงสร้างหลักของ Backend ในการกำหนด API Routes ทั้งหมด เช่น `/api/credit-request`, `/api/scorecard` เป็นต้น พร้อมทั้งใช้ระบบ Middleware ของ Express ในการจัดการความปลอดภัย ตรวจสอบ Token และจัดการข้อผิดพลาด (Error Handling) ก่อนจะส่งข้อมูลไปยังส่วนการประมวลผลฐานข้อมูล
