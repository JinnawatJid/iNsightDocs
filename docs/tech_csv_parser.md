## 2.7.X csv-parser

**csv-parser** เป็นไลบรารีใน Node.js ที่ใช้สำหรับอ่านและวิเคราะห์ไฟล์ CSV (Comma-Separated Values) โดยถูกออกแบบมาให้ทำงานในรูปแบบของสตรีม (Stream) เพื่อให้มีประสิทธิภาพสูงและประหยัดหน่วยความจำ

**จุดเด่นที่สำคัญ:**
*   **ประหยัดหน่วยความจำ (Low Memory Footprint):** ด้วยการทำงานแบบสตรีม ทำให้สามารถอ่านและประมวลผลไฟล์ CSV ขนาดใหญ่มากๆ ได้โดยไม่ต้องโหลดข้อมูลทั้งหมดเข้าไปในหน่วยความจำทีเดียว
*   **ความรวดเร็วสูง:** เป็นหนึ่งในไลบรารีวิเคราะห์ CSV ที่เร็วที่สุดใน Node.js
*   **ความสะดวกในการใช้งาน:** แปลงข้อมูลแต่ละแถวใน CSV ให้เป็นรูปแบบ JSON Object โดยอัตโนมัติ ทำให้ผู้พัฒนาสามารถนำค่าของแต่ละคอลัมน์ไปประมวลผลต่อได้ทันที

**การประยุกต์ใช้ในระบบ:**
ในระบบนี้ csv-parser ถูกนำมาใช้ในขั้นตอนการเริ่มต้นระบบ (Database Seeding) โดยเฉพาะอย่างยิ่งการนำเข้าข้อมูลบัญชีดำลูกค้า (Customer Blacklist) หรือข้อมูลตั้งค่าเริ่มต้น จากไฟล์ CSV เข้าสู่ฐานข้อมูลของระบบ เพื่อเตรียมความพร้อมให้ระบบสามารถใช้งานได้ทันทีโดยไม่ต้องป้อนข้อมูลพื้นฐานเอง
