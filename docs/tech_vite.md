## 2.7.X Vite

**Vite** (อ่านว่า "วิท") เป็นเครื่องมือสำหรับสร้างและจัดการโปรเจกต์ส่วนหน้า (Frontend Build Tool) รุ่นใหม่ ที่ถูกสร้างขึ้นมาเพื่อแก้ปัญหาความล่าช้าในการพัฒนา (Development Experience) ของเครื่องมือยุคเก่าอย่าง Webpack

**จุดเด่นที่สำคัญ:**
*   **ความเร็วในการเริ่มต้นเซิร์ฟเวอร์ (Instant Server Start):** Vite ทำงานโดยใช้ความสามารถของ Native ES Modules ในเบราว์เซอร์ ทำให้ไม่ต้องใช้เวลาในการรวมไฟล์ (Bundling) ก่อนที่เซิร์ฟเวอร์จะพร้อมทำงาน ส่งผลให้ระบบเริ่มต้นได้ไวมากแม้ในโปรเจกต์ที่มีขนาดใหญ่
*   **Hot Module Replacement (HMR) ที่รวดเร็ว:** เมื่อนักพัฒนาแก้ไขโค้ด Vite จะทำการอัปเดตเฉพาะโมดูลที่ถูกแก้ไขไปที่เบราว์เซอร์ทันที โดยไม่ต้องรีโหลดหน้าเว็บใหม่ทั้งหมด ช่วยเพิ่มความรวดเร็วในการพัฒนาอย่างมาก
*   **Optimized Build:** เมื่อต้องการนำโปรแกรมไปใช้งานจริง (Production) Vite จะใช้ Rollup ในการมัดรวมไฟล์ (Bundle) ซึ่งให้ผลลัพธ์ไฟล์ที่มีขนาดเล็กและมีประสิทธิภาพสูง

**การประยุกต์ใช้ในระบบ:**
ระบบนี้ใช้ Vite เป็นเครื่องมือหลักในการสร้างและจำลองเซิร์ฟเวอร์สำหรับส่วน Frontend เพื่อให้นักพัฒนาสามารถเขียนโค้ดและเห็นผลลัพธ์ได้อย่างรวดเร็ว นอกจากนี้ยังใช้สำหรับรวบรวมและสร้างไฟล์ (Build Artifacts) ก่อนนำไปผสานกับ Node.js สำหรับการติดตั้งใช้งานจริง
