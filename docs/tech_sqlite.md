## 2.7.X SQLite

**SQLite** เป็นเครื่องมือฐานข้อมูลเชิงสัมพันธ์ขนาดเล็กที่ทำงานในรูปแบบของไลบรารีซอฟต์แวร์ (C-language library) โดยไม่ต้องอาศัยกระบวนการจำลองเซิร์ฟเวอร์ฐานข้อมูล (Serverless) ฐานข้อมูลทั้งหมดจะถูกจัดเก็บไว้ในไฟล์เดี่ยวๆ เพียงไฟล์เดียว

**จุดเด่นที่สำคัญ:**
*   **ไม่ต้องติดตั้ง (Zero-Configuration):** ไม่ต้องติดตั้งหรือตั้งค่าเซิร์ฟเวอร์ฐานข้อมูลใดๆ เพียงแค่โปรแกรมมีสิทธิ์อ่านและเขียนไฟล์ก็สามารถใช้งานฐานข้อมูลได้ทันที
*   **ความเบาและกะทัดรัด:** เป็นฐานข้อมูลที่กินทรัพยากรน้อยมาก แต่ยังคงรองรับคำสั่ง SQL มาตรฐานได้อย่างครบถ้วน
*   **ความสะดวกในการจำลองสภาพแวดล้อม:** ช่วยให้นักพัฒนาสามารถทดสอบหรือรันโปรแกรมในเครื่องส่วนตัวได้อย่างรวดเร็ว

**การประยุกต์ใช้ในระบบ:**
แม้ว่าระบบหลักจะออกแบบมาเพื่อใช้ MSSQL แต่ SQLite ถูกนำมาใช้ในสภาพแวดล้อมการพัฒนา (Development) และการทดสอบ (Testing) เนื่องจากความสะดวกในการจำลองฐานข้อมูลขึ้นมาใหม่เมื่อมีการลบฐานข้อมูลทิ้ง ช่วยลดภาระในการต้องเชื่อมต่อเซิร์ฟเวอร์ฐานข้อมูลขององค์กร นอกจากนี้ยังช่วยให้สามารถนำระบบไปสาธิตการทำงาน (Demonstration) ได้ในทุกเครื่องทันทีโดยไม่ต้องพึ่งพาระบบเครือข่าย
