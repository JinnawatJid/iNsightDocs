## 2.7.X Microsoft SQL Server (MSSQL)

**Microsoft SQL Server** เป็นระบบจัดการฐานข้อมูลเชิงสัมพันธ์ (Relational Database Management System - RDBMS) ระดับองค์กรที่พัฒนาโดยไมโครซอฟท์ ได้รับความนิยมอย่างกว้างขวางในองค์กรธุรกิจเนื่องจากความเสถียรและความปลอดภัย

**จุดเด่นที่สำคัญ:**
*   **ความปลอดภัยระดับองค์กร:** มีระบบการจัดการสิทธิ์และเข้ารหัสข้อมูลที่มีมาตรฐานสูง เหมาะสำหรับการจัดเก็บข้อมูลทางธุรกิจและการเงิน
*   **ความน่าเชื่อถือและการขยายขยายตัว (Scalability):** สามารถรองรับข้อมูลปริมาณมหาศาล และรองรับธุรกรรม (Transactions) จำนวนมากได้โดยที่ประสิทธิภาพไม่ลดลง
*   **การบูรณาการกับระบบองค์กร:** สามารถเชื่อมต่อและแลกเปลี่ยนข้อมูลกับระบบอื่นๆ ภายในโครงสร้างพื้นฐานของไมโครซอฟท์ได้อย่างไร้รอยต่อ

**การประยุกต์ใช้ในระบบ:**
Microsoft SQL Server ถูกกำหนดให้เป็นระบบฐานข้อมูลหลักสำหรับสภาพแวดล้อมใช้งานจริง (Production Environment) ของโปรเจกต์นี้ โดยใช้ในการจัดเก็บข้อมูลสำคัญทั้งหมด เช่น ข้อมูลลูกค้า, ประวัติคำขออนุมัติเครดิต, การตั้งค่าระบบ Workflow และข้อมูล Scorecard ทั้งนี้ ระบบได้ใช้ไลบรารี `mssql` ใน Node.js เพื่อเชื่อมต่อและประมวลผลคำสั่ง SQL ผ่านโครงสร้างพารามิเตอร์เพื่อป้องกันการถูกโจมตีแบบ SQL Injection
