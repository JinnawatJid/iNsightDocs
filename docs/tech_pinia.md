## 2.7.X Pinia

**Pinia** เป็นไลบรารีสำหรับจัดการสถานะ (State Management Library) อย่างเป็นทางการสำหรับ Vue.js ซึ่งถูกพัฒนาขึ้นมาเพื่อทดแทน Vuex โดยมีเป้าหมายเพื่อให้การเขียนโค้ดมีความเรียบง่าย สั้นกระชับ และทำงานร่วมกับ TypeScript ได้อย่างสมบูรณ์แบบ

**จุดเด่นที่สำคัญ:**
*   **รองรับ Composition API:** Pinia ถูกออกแบบมาให้ทำงานร่วมกับ Composition API ของ Vue 3 ได้อย่างเป็นธรรมชาติ ทำให้การเขียน Store สำหรับเก็บข้อมูลมีความคล้ายกับการเขียนคอมโพเนนต์ปกติ
*   **ไม่มี Mutations:** แตกต่างจาก Vuex ที่ต้องมี Mutations เพื่อเปลี่ยนค่า State ใน Pinia นักพัฒนาสามารถเปลี่ยนแปลงค่า State ได้โดยตรงหรือผ่าน Actions ทำให้ลดความซ้ำซ้อนของโค้ด
*   **รองรับ TypeScript สบายๆ (Type Safe):** มีการออกแบบให้รองรับ Type Inference อย่างสมบูรณ์ ทำให้เครื่องมือพัฒนาสามารถเดาประเภทข้อมูลและแจ้งเตือนข้อผิดพลาดได้ดีขึ้น

**การประยุกต์ใช้ในระบบ:**
ระบบนี้ใช้ Pinia เป็นศูนย์กลางในการเก็บและจัดการข้อมูลที่มีการใช้งานร่วมกันในหลายๆ หน้าจอ เช่น ข้อมูลผู้ใช้งานที่เข้าสู่ระบบ (User Session), ข้อมูลของคำขออนุมัติเครดิต (Credit Request Data), และข้อมูลตั้งค่าระบบ เพื่อให้ทุกคอมโพเนนต์สามารถเข้าถึงข้อมูลที่ถูกต้องและเป็นชุดเดียวกัน
