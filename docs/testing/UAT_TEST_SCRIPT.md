# เอกสารทดสอบระบบ (UAT Script) - การสร้างคำขอเครดิต

เอกสารนี้จัดทำขึ้นเพื่อให้ตัวแทนผู้ใช้งาน (User Champion) ใช้ในการทดสอบระบบ (User Acceptance Test) เพื่อตรวจสอบความถูกต้องของฟิลด์ข้อมูล, การแจ้งเตือน (Validation), และขั้นตอนการสร้างคำขอเครดิตตั้งแต่ต้นจนจบ (Draft -> Submit)

---

## 1. การเตรียมตัวก่อนเริ่มทดสอบ (Preparation)

1. **เข้าระบบ:** เปิดหน้าจอสร้างคำขอเครดิต
2. **ข้อมูลทดสอบ:** แนะนำให้ใช้รหัสลูกค้าต่อไปนี้ในการค้นหา:
   - `01016AY`
   - `01017AY`
   - `01018AY`
3. **ไฟล์ทดสอบ:** เตรียมไฟล์รูปภาพ (.jpg, .png) หรือ PDF อะไรก็ได้ไว้บนหน้าจอเพื่อใช้ทดสอบการอัปโหลด (ไม่ต้องใช้เอกสารจริง)

---

## 2. ขั้นตอนการทดสอบ (Test Scenarios)

### กรณีทดสอบที่ 1: การตรวจสอบข้อมูลบังคับ (Validation Check)
*เป้าหมาย: เพื่อยืนยันว่าระบบป้องกันไม่ให้ส่งข้อมูลที่ไม่ครบถ้วน และมีการแจ้งเตือนที่ถูกต้อง*

1. **ค้นหาลูกค้า:** พิมพ์รหัสลูกค้า (เช่น `01016AY`) แล้วกดค้นหา
2. **ข้ามการกรอกข้อมูล:** **ไม่ต้องกรอกข้อมูลใดๆ** และ **ไม่ต้องแนบไฟล์**
3. **กดปุ่มส่ง:** เลื่อนลงไปด้านล่างสุด แล้วกดปุ่ม **"ส่งคำขออนุมัติ" (Submit)**
4. **ตรวจสอบผลลัพธ์:**
   - [ ] ต้องมีหน้าต่างแจ้งเตือน (Alert) ระบุว่ากรุณากรอกข้อมูลให้ครบถ้วน
   - [ ] ช่องที่มีเครื่องหมายดอกจันสีแดง (*) จะต้องแสดงขอบสีแดง
   - [ ] ระบบต้อง **ไม่** ทำการส่งข้อมูลไปที่ Server

---

### กรณีทดสอบที่ 2: การสร้างคำขอเครดิตที่สมบูรณ์ (Happy Path)
*เป้าหมาย: เพื่อยืนยันว่าเมื่อกรอกข้อมูลครบถ้วน สามารถส่งคำขอได้สำเร็จ*

**ขั้นตอนที่ 1: แท็บข้อมูลคำขอ (Request Info)**
1. **แนบเอกสาร:** อัปโหลดไฟล์ในช่อง "เอกสารขอเปิดเครดิต" (บังคับ)
2. **ข้อมูลผู้ติดต่อ:** กรอกชื่อ, ตำแหน่ง, และเบอร์โทรศัพท์ (บังคับ)
3. **รายละเอียดคำขอ:**
   - ระบุวงเงินที่ต้องการ (เช่น 500,000)
   - ระบุระยะเวลาเครดิต (Credit Term) แยกตาม 3 กลุ่มสินค้า (กระจก/กาว, อลูมิเนียม/Acc, ยิปซั่ม/ซีไลน์)
   - เลือกเหตุผลการขอเครดิต (เช่น สต๊อคสินค้า)

**ขั้นตอนที่ 2: แท็บข้อมูลทั่วไป (General Info)**
1. **แนบเอกสาร:** อัปโหลด "สำเนาบัตรประชาชน" และ "สำเนาทะเบียนบ้าน" (บังคับ)
2. **ผู้มีอำนาจลงนาม:** กรอกชื่อและตำแหน่ง ของผู้มีอำนาจลงนามคนที่ 1 (บังคับ)

**ขั้นตอนที่ 3: แท็บที่อยู่ร้านค้า/บริษัท (Store/Company)**
1. **แนบเอกสาร:** อัปโหลดเอกสารบังคับตามประเภทลูกค้า (หนังสือรับรอง/ทะเบียนพาณิชย์, ภ.พ.20, รูปถ่ายร้าน, สัญญาเช่า/ที่ดิน)
2. **ข้อมูลที่อยู่:** ตรวจสอบความถูกต้อง

**ขั้นตอนที่ 4: แท็บที่อยู่อาศัย (Residence)**
1. **แนบเอกสาร:** อัปโหลด "รูปถ่ายบ้าน" และ "เอกสารเสียภาษีที่ดิน" (บังคับ)
2. **ที่อยู่:** ตรวจสอบว่าข้อมูลที่อยู่ดึงมาจากระบบถูกต้อง (แก้ไขได้ถ้าต้องการ)
3. **รายละเอียด:** ระบุลักษณะที่ตั้ง และ กรรมสิทธิ์ (เช่น บ้านตนเอง)

**ขั้นตอนที่ 5: แท็บเอกสารการเงิน (Financial)**
1. **แนบเอกสาร:** อัปโหลด "Bank Statement" (บังคับ)
2. **ข้อมูลการเงิน:** ตรวจสอบการแสดงผลข้อมูลยอดขาย (ถ้ามี)

**ขั้นตอนที่ 6: ยืนยันการส่ง**
1. กดปุ่ม **"ส่งคำขออนุมัติ" (Submit)**
2. **ตรวจสอบผลลัพธ์:**
   - [ ] แสดงข้อความ "บันทึกข้อมูลสำเร็จ" (Success)
   - [ ] หน้าจอ Refresh กลับมาสู่สถานะเริ่มต้น หรือไปที่หน้ารายการคำขอ
