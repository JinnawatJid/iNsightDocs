# รายการฟิลด์ในระบบ (System-As-Built Field Inventory)

เอกสารนี้รวบรวมรายการอินพุตฟิลด์และไฟล์แนบทั้งหมดที่มีอยู่ในหน้าสร้างคำขอเครดิต (Credit Request) เพื่อใช้สำหรับตรวจสอบความครบถ้วนของระบบเทียบกับความต้องการของผู้ใช้งาน

**คำอธิบายสัญลักษณ์ (Legend):**
- **กฎการตรวจสอบ (Validation Rules):**
    - **ตัวเลขเท่านั้น:** อนุญาตเฉพาะตัวเลข 0-9 (อาจมีลูกน้ำคั่น)
    - **ตัวเลขเท่านั้น (9-10 หลัก):** อนุญาตเฉพาะตัวเลขความยาว 9-10 หลัก
    - **ตัวอักษรเท่านั้น:** ห้ามมีตัวเลข (อนุญาตภาษาไทย อังกฤษ เว้นวรรค วงเล็บ จุด)
    - **ตัวอักษรและตัวเลข:** กรอกได้ทั้งตัวอักษรและตัวเลข
- **แสดงผล (*):** มีดอกจันสีแดงแสดงในหน้าจอ (Visual UI)
- **การบังคับ (Logic Enforced):**
    - **บังคับ:** จำเป็นต้องกรอกข้อมูล หากไม่กรอกจะไม่สามารถส่งคำขอหรือระบบจะแจ้งเตือนให้กรอก
    - **ไม่บังคับ:** ไม่จำเป็นต้องกรอกข้อมูล

> ฟิลด์นี้ใช้แหล่งข้อมูล 2 ชั้นตามลำดับความสำคัญ:
