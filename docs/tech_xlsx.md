## 2.7.X xlsx (SheetJS)

**xlsx** หรือเป็นที่รู้จักในนาม **SheetJS** เป็นไลบรารี JavaScript ที่มีความสามารถสูงในการอ่าน วิเคราะห์ (Parse) และเขียนไฟล์ตารางคำนวณ (Spreadsheet) หลากหลายรูปแบบ เช่น Excel (.xlsx, .xls), CSV, และอื่นๆ

**จุดเด่นที่สำคัญ:**
*   **ไม่พึ่งพาโปรแกรมเสริม:** สามารถประมวลผลไฟล์ Excel ได้ด้วยตัวเองโดยไม่จำเป็นต้องติดตั้ง Microsoft Office หรือโปรแกรมอื่นๆ ลงบนเครื่องเซิร์ฟเวอร์
*   **การรองรับไฟล์หลายรูปแบบ:** สนับสนุนรูปแบบไฟล์ของ Spreadsheet ได้ครอบคลุมมากที่สุดในบรรดาไลบรารีประเภทเดียวกัน
*   **ประสิทธิภาพการแปลงข้อมูล:** สามารถแปลงข้อมูลจากรูปแบบตารางให้กลายเป็น JSON Array หรือแปลง JSON Array กลับเป็นไฟล์ Excel ได้อย่างรวดเร็ว ทำให้ง่ายต่อการนำข้อมูลไปใช้งานต่อในโปรแกรม

**การประยุกต์ใช้ในระบบ:**
ระบบนำ SheetJS มาใช้ในกระบวนการวิเคราะห์ข้อมูลทางการเงิน (Financial Excel Parser) เช่น อ่านไฟล์งบดุล (Balance Sheet) หรืองบกำไรขาดทุน (Income Statement) ที่ผู้ใช้อัปโหลดเข้ามา เพื่อทำการดึงค่าตัวเลขที่สำคัญ เช่น รายได้สุทธิ สินทรัพย์รวม แล้วนำค่าเหล่านั้นมาคำนวณผ่าน Scoring Engine อัตโนมัติ โดยที่ผู้ใช้ไม่ต้องกรอกข้อมูลทีละช่องด้วยตนเอง
