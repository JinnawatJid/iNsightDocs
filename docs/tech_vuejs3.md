## 2.7.X Vue.js 3

**Vue.js 3** เป็นโปรเกรสซีฟเฟรมเวิร์ก (Progressive Framework) สำหรับภาษา JavaScript ที่ใช้ในการสร้างส่วนติดต่อผู้ใช้งาน (User Interface) และแอปพลิเคชันแบบหน้าเดียว (Single-Page Applications - SPA) โดย Vue.js ถูกออกแบบมาให้สามารถเรียนรู้ได้ง่าย นำไปใช้งานร่วมกับไลบรารีอื่นได้สะดวก และมีประสิทธิภาพสูง

**จุดเด่นที่สำคัญ:**
*   **Composition API:** เป็นรูปแบบการเขียนโค้ดแบบใหม่ใน Vue 3 ที่ช่วยให้นักพัฒนาสามารถจัดการและนำตรรกะของโปรแกรม (Logic) กลับมาใช้ซ้ำได้ง่ายขึ้น ทำให้โครงสร้างโค้ดเป็นระเบียบและดูแลรักษาได้ง่ายกว่า Options API ในเวอร์ชันก่อน
*   **Virtual DOM ที่รวดเร็ว:** มีการปรับปรุง Virtual DOM ให้ทำงานได้เร็วขึ้น ช่วยลดการใช้ทรัพยากรและเพิ่มความเร็วในการตอบสนองของแอปพลิเคชัน
*   **Reactivity System:** ระบบตรวจจับการเปลี่ยนแปลงข้อมูลที่มีประสิทธิภาพสูง ทำให้หน้าจออัปเดตอัตโนมัติทันทีเมื่อข้อมูลในระบบเปลี่ยนไป

**การประยุกต์ใช้ในระบบ:**
ในระบบนี้ Vue.js 3 ถูกนำมาใช้เป็นเทคโนโลยีหลักในการพัฒนาส่วน Frontend ทั้งหมด เพื่อสร้างประสบการณ์การใช้งานที่ลื่นไหล ผู้ใช้สามารถกรอกข้อมูล ดูรายงานการประเมินเครดิต และเปลี่ยนหน้าต่างต่างๆ ภายในระบบได้โดยที่หน้าเว็บไม่ต้องโหลดใหม่ (Page Reload)
