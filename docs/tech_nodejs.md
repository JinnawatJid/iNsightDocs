## 2.7.X Node.js

**Node.js** เป็นสภาพแวดล้อมการทำงานของภาษา JavaScript (JavaScript Runtime Environment) แบบเปิด (Open-source) ที่ทำงานแบบข้ามแพลตฟอร์ม (Cross-platform) โดยใช้เอนจิน V8 ของ Google Chrome ทำให้สามารถเขียนภาษา JavaScript ให้ทำงานฝั่งเซิร์ฟเวอร์ (Server-side) ได้

**จุดเด่นที่สำคัญ:**
*   **Asynchronous & Event-driven:** ทำงานแบบไม่ปิดกั้น (Non-blocking I/O) ทำให้รองรับการเชื่อมต่อพร้อมๆ กันจำนวนมากได้ดี โดยไม่ทำให้เซิร์ฟเวอร์ทำงานช้าลง
*   **ภาษาเดียวทั้งระบบ (Single Language):** นักพัฒนาสามารถใช้ JavaScript ทั้งในส่วน Frontend และ Backend ช่วยลดความซับซ้อนในการเรียนรู้ภาษาหลายภาษาและเอื้อต่อการแชร์โค้ดร่วมกัน
*   **มีไลบรารีสนับสนุนมหาศาล:** มีระบบจัดการแพ็กเกจ NPM (Node Package Manager) ซึ่งเป็นแหล่งรวบรวมไลบรารีที่ใหญ่ที่สุด ทำให้การเพิ่มความสามารถต่างๆ ให้ระบบทำได้ง่ายและรวดเร็ว

**การประยุกต์ใช้ในระบบ:**
ระบบใช้ Node.js เป็นแพลตฟอร์มหลักในการพัฒนา Backend เพื่อจัดการกับระบบฐานข้อมูล, การรับส่งไฟล์, การคำนวณ Credit Score, และให้บริการ RESTful API แก่ส่วน Frontend นอกจากนี้ยังใช้สำหรับรวบรวมระบบทั้งหมดเพื่อแพ็กเกจเป็นไฟล์รันไทม์ไฟล์เดียว (Standalone Executable) สำหรับติดตั้งบนเซิร์ฟเวอร์ปลายทางแบบไม่ต้องพึ่งพาไลบรารีภายนอก
